# Ashwing: Broom Aces

Portfolio and dev log for a solo Godot 4 aerial-combat game where battle-mages fly enchanted
brooms. The site is served from this repo's root by GitHub Pages.

**Site:** https://fenskek.github.io/Ashwing-Broom-Aces/

- `index.html`, `style.css`: the page (no build step)
- `img/`: in-game captures from the game's screenshot tests, concept sheets, Tripo tests
